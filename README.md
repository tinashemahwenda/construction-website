# Kuvaka Construction Website

A responsive website for Kuvaka Construction company based in Zimbabwe. Built with HTML, Tailwind CSS, and JavaScript.

## Tech Stack
- HTML5
- CSS3
- Tailwind CSS
- JavaScript (Vanilla)

## Setup Instructions
1. Clone this repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start development server:
   ```bash
   npm run dev
   ```

## Project Structure
```
├── index.html
├── styles/
│   └── main.css
├── images/
├── js/
│   └── main.js
└── tailwind.config.js
```

## Development
This project uses Tailwind CSS for styling. The development server will watch for changes and recompile the CSS automatically.
